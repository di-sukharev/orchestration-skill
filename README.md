# orchestration

Исполнитель изучает код и выбирает режим:

- **Light:** локальное изменение, понятное поведение и способ проверки —
  реализация и проверки без промежуточных согласований.
- **Full:** связанные изменения, миграции или существенная неопределённость —
  лид одобряет план; контрольные точки нужны только для существенных решений.

Если сложность обнаружилась в процессе, исполнитель сообщает до расширения работ.
В задании — конкретные сценарии приёмки и связанные риски; в итоговом отчёте —
результат, изменённые файлы, проверки и нерешённые вопросы.
UX — продуманный, простой и элегантный; UI — минималистичный, без лишних кликов,
модалок и кнопок.

Лид напрямую управляет саб-агентами, не читает проектные файлы и их истории;
задаёт открытые вопросы только при существенной неопределённости.
Лид отвечает за качество и срок: каждый шаг продвигает задачу или снимает неопределённость.
Во время работы саб-агентов лид избегает частых запросов статуса и повторяющихся обновлений.
Свежий проверяющий саб-агент проверяет всю задачу и зависимости по исходным
требованиям, сообщает дефекты, воспроизведение, тесты и минимальные исправления.
Лид принимает замечания, тот же саб-агент исправляет; следующий проверяет заново.

Перед передачей реализации или исправлений саб-агент выполняет полезные для
изменений и обязательные в проекте проверки, пропуская лишние и повторные.
Готово: принятые замечания и существенные пробелы ревью закрыты, проверки прошли.
Препятствия решаются внутри
задачи; остановка — только для действия человека. Саб-агенты работают по коду,
для визуальной проверки браузер не открывают и приложение не прокликивают.
Визуальная приёмка — пользователю.
Посторонние изменения не трогаем и не включаем в работу, ревью и коммиты.
Работаем в текущей ветке, если не указано иное. Продакшен, новые ветки и worktree —
только с разрешения пользователя. [Полный протокол](orchestration/SKILL.md).

## Установка и запуск

Отправьте агенту:

```text
Install this skill globally: https://github.com/di-sukharev/orchestration-skill
```

Или скопируйте `orchestration` в `~/.codex/skills/` либо `~/.claude/skills/`.
Нужны саб-агенты; другие скиллы не требуются.

```text
$orchestration
Implement X. Use gpt-5.6-luna for all subagents.
```

Claude Code: `/orchestration`. Модель всех саб-агентов задаётся обычным текстом.
По умолчанию: Codex — `gpt-5.6-luna`, Claude Code — `sonnet`.
Недоступную модель не подменяем.
