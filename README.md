# orchestration-skill

Главная модель — лид, Luna — исполнители. Цель — абсолютно достаточная реализация
за минимум времени и токенов. Решения — минимально достаточные, без лишней работы.

Luna находит нужный код, лид изучает его и разбивает задачу на небольшие подзадачи.
Выдаёт их исполнителю по одной, с точным Definition of Done; следующую — после
проверки предыдущей. Общение — короткими отчётами, без чтения
истории саб-агентов. На каждый проход ревью приходит новый агент; согласованные
с лидом замечания он исправляет сам. Размер задач и смена исполнителя — на
усмотрение лида. Готовность подтверждается результатом, проверками и чистым ревью.

## Установка

Отправьте агенту:

```text
Установи этот скилл глобально: https://github.com/di-sukharev/orchestration-skill
```

Или скопируйте папку `orchestration` в `~/.codex/skills/`
(для Claude Code — `~/.claude/skills/`). Другие скиллы не нужны.

## Использование

```text
$orchestration
Реализуй Х. Сначала составь план, затем выполни его через саб-агентов.
```

Для одного плана добавьте: «Код пока не меняй». По умолчанию саб-агенты используют
`gpt-5.6-luna`; другую модель можно указать в запросе. Нужна среда с поддержкой
саб-агентов и выбранной модели. Скилл не даёт отдельного разрешения на коммиты,
push или деплой.
