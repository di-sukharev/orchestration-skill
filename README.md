# orchestration-skill

Саб-агенты реализуют задачу и проводят независимое ревью.

## Установка

```text
Установи глобально эти скиллы:
https://github.com/di-sukharev/orchestration-skill
https://github.com/di-sukharev/loop-code-review-skill
```

## Использование

```text
/orchestration
Реализуй <текст задачи>.
```

Оркестратор выбирает доступные модель и effort для каждой подзадачи:

- Простая задача — лёгкая модель, `medium`.
- Средняя сложность — сбалансированная модель, `high`.
- Сложная или рискованная задача — сильная модель, `xhigh`, если оправдан и поддерживается; иначе `high`.

Минимальный effort — `medium`. Золотая середина и основной выбор — `high`.

Модель и effort оцениваются отдельно. При росте сложности или отсутствии прогресса оркестратор повышает effort или выбирает более сильную модель. Для ревью учитываются риски изменений.

Ваши настройки имеют приоритет. Можно задать модель, effort или оба:

```text
Используй <модель> с effort <уровень> для всех саб-агентов.
```
