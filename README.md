# orchestration-skill

Оркестратор пишет план. Саб-агенты исследуют код, выполняют подзадачи и проводят независимое ревью.

## Установка

```text
Установи глобально эти скиллы:
https://github.com/di-sukharev/orchestration-skill
https://github.com/di-sukharev/loop-code-review-skill
```

## Использование

```text
/orchestration
Реализуй <текст задачи>.
```

1. Luna в Codex или Sonnet в Claude Code исследует код под задачу.
2. Оркестратор задаёт Definition of Done, UX/DX, подзадачи, риски и проверки.
3. Агент выполняет по одной подзадаче. Оркестратор принимает результат по плану.
4. После реализации свежие агенты проводят общее ревью через `loop-code-review`. Оркестратор выбирает модель и effort по риску.
5. После успешного ревью оркестратор делает commit и push в рамках разрешения пользователя.

Цель — экономить токены с учётом повторных попыток. Оркестратор получает компактные отчёты и не читает истории агентов. Для сложной работы он может выбрать более сильную модель.

Ваши настройки имеют приоритет. Можно задать модель, effort или оба:

```text
Используй <модель> с effort <уровень> для всех саб-агентов.
```
