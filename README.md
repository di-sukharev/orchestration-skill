# orchestration-skill

Саб-агенты реализуют задачу и проводят независимое ревью.

## Установка

```text
Установи глобально эти скиллы:
https://github.com/di-sukharev/orchestration-skill
https://github.com/di-sukharev/loop-code-review-skill
```

## Использование

```text
/orchestration
Реализуй <текст задачи>.
```

По умолчанию: `gpt-5.6-luna` (Codex), `sonnet` (Claude Code).
Другую модель задайте отдельно:

```text
Используй <модель> для всех саб-агентов.
```
