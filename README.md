# Orchestration

Для нескольких крупных задач. Каждую выполняет новый саб-агент, чтобы контексты задач не перемешивались.

Задачи идут по очереди. Независимые задачи можно выполнять параллельно, если их изменения не конфликтуют.

Саб-агент изучает код, пишет план, реализует задачу и запускает [Loop Code Review](https://github.com/di-sukharev/loop-code-review-skill). Тот создаёт независимых агентов для ревью и исправления проблем. Основная сессия запускает задачи и сообщает о прогрессе.

По умолчанию задачи выполняет сильная модель (Sol или Opus) с высоким уровнем рассуждения. Можно указать свою модель и уровень.

Скилл объединяет Orchestration и [Loop Tasks](https://github.com/di-sukharev/loop-tasks-skill). Loop Tasks больше не поддерживается отдельно.

## Установка

Отправьте агенту это сообщение.

```text
Установи скиллы глобально
https://github.com/di-sukharev/orchestration-skill
https://github.com/di-sukharev/loop-code-review-skill
```

## Запуск

Попросите выполнить несколько крупных задач или напишите `/orchestration <задачи>`. Можно передать список или файл с задачами.

В конце каждой задачи саб-агент сообщает результат, проверки и статус ревью, а также предлагает сообщение коммита. Коммит и пуш — только по прямой просьбе пользователя.

## Другие скиллы

- [Code Scout](https://github.com/di-sukharev/code-scout-skill) — саб-агент ищет нужный код и передаёт результаты основному агенту.
- [Loop Code Review](https://github.com/di-sukharev/loop-code-review-skill) — независимые саб-агенты находят и исправляют проблемы в изменениях.
- [Refactoring](https://github.com/di-sukharev/refactoring-skill) — упрощает код и убирает ненужные части без изменения поведения.
