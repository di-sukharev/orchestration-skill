# Orchestration

Для нескольких крупных задач. Каждую выполняет новый саб-агент без истории чата. Он получает путь к репозиторию, свою задачу, критерии готовности и нужный контекст.

По умолчанию задачи идут по очереди. Независимые задачи можно выполнять параллельно, если их изменения не конфликтуют. Зависимые задачи запускаются после завершения необходимых им задач.

Саб-агент изучает код, пишет план, реализует задачу, выполняет проверки и запускает [Loop Code Review](https://github.com/di-sukharev/loop-code-review-skill) только на своих изменениях. Тот создаёт независимых агентов для ревью и исправления проблем.

Основная сессия только запускает агентов, координирует задачи и сообщает о прогрессе, результатах и блокерах. Вся работа по задачам, включая исследование кода, реализацию, проверки и ревью, остаётся у саб-агентов.

По умолчанию задачи выполняет сильная модель (Sol или Opus) с высоким уровнем рассуждения. Можно указать свою модель и уровень.

Скилл объединяет Orchestration и [Loop Tasks](https://github.com/di-sukharev/loop-tasks-skill). Loop Tasks больше не поддерживается отдельно.

## Установка

Отправьте агенту это сообщение.

```text
Установи скиллы глобально
https://github.com/di-sukharev/orchestration-skill
https://github.com/di-sukharev/loop-code-review-skill
```

## Запуск

Попросите выполнить несколько крупных задач или напишите `/orchestration <задачи>`. Можно передать список или файл с задачами.

В конце каждой задачи саб-агент сообщает результат, проверки и статус ревью, а также предлагает сообщение коммита. Задача завершена, только когда соответствующие проверки прошли и ревью получило статус `passed`. Иначе саб-агент сообщает, что задача не завершена, и объясняет, что осталось сделать.

Коммит и пуш — только по прямой просьбе пользователя.

## Другие скиллы

- [Code Scout](https://github.com/di-sukharev/code-scout-skill) — саб-агент ищет нужный код и передаёт результаты основному агенту.
- [Loop Code Review](https://github.com/di-sukharev/loop-code-review-skill) — независимые саб-агенты находят и исправляют проблемы в изменениях.
- [Refactoring](https://github.com/di-sukharev/refactoring-skill) — упрощает код и убирает ненужные части без изменения поведения.
