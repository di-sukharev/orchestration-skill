# orchestration-skill

Главная модель — лид, Luna — исполнители. Цель — абсолютно достаточная реализация
за минимум времени и токенов. Решения — минимально достаточные, без лишней работы.
Все acceptance criteria должны быть выполнены. UX/UI — максимально простой
в рамках требований; необязательные улучшения пользователь запросит отдельно.

Luna находит нужный код, лид изучает его и разбивает задачу на небольшие подзадачи.
Каждая даёт законченный проверяемый результат без лишних затрат на координацию.
Лид выдаёт их исполнителю по одной, с точным definition of done; следующую — после
проверки предыдущей. Общение — короткими отчётами, без чтения истории саб-агентов.
На каждый проход ревью приходит новый агент; согласованные
с лидом замечания он исправляет сам. Размер задач и смена исполнителя — на
усмотрение лида. Готовность подтверждается результатом, проверками и чистым ревью.
Ревью ищет существенные системные ошибки; визуальную проверку выполняет пользователь.
Браузер и браузерные тесты запускаются только по явной просьбе.

## Установка

Отправьте агенту:

```text
Install this skill globally: https://github.com/di-sukharev/orchestration-skill
```

Или скопируйте папку `orchestration` в `~/.codex/skills/`
(для Claude Code — `~/.claude/skills/`). Другие скиллы не нужны.

## Использование

```text
$orchestration
Implement X. First create a plan, then execute it through subagents.
```

Для одного плана добавьте: «Do not change code yet». По умолчанию саб-агенты используют
`gpt-5.6-luna`; другую модель можно указать в запросе. Нужна среда с поддержкой
саб-агентов и выбранной модели. Скилл не даёт отдельного разрешения на коммиты,
push или деплой.
